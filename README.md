# KuroCube Bike Computer

Велокомпьютер на Python и PyQt6 с поддержкой UART (GPS) и локализацией.

## Особенности
- Отображение скорости, средней и максимальной скорости.
- Пробег за поездку и общий пробег.
- Переключение языков (Русский / Английский).
- Переключение единиц измерения (Км/Мили, °C/°F).
- Сохранение настроек в config.ini.
